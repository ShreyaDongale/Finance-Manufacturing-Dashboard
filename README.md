# Finance & Manufacturing Dashboard

## Project Overview
This project focuses on analyzing financial and manufacturing data using an interactive Power BI dashboard to generate meaningful business insights.

## Tools Used
- Microsoft Excel
- Power BI

## Key Features
- Financial performance analysis
- Manufacturing data analysis
- KPI cards and interactive visuals
- Data visualization and reporting
- Business insights through dashboards

## Project Files
- Excel dataset
- Power BI dashboard (.pbix)
